# Examples — planned

Runnable examples will be added with the shared runtime. This foundation contains no example video-generation command.

The intended progression is a minimal scene, a character motion lab, a 45–60 second film, and product, educational, and fictional-story examples. Each example must use redistributable inputs, declare providers/dependencies, and include a reproducible render command and expected output metadata.

See the [generalization and release criteria](../docs/RELEASE_STANDARD.md).
