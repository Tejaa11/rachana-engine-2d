# Shared engine modules — planned

This directory will hold reusable engine packages as they are implemented. No runtime package exists yet.

The proposed boundaries are schema, runtime, motion, assets, providers, audio, workflow, rendering, and quality. The CLI and creator studio will consume the same services.

Start with the [architecture](../docs/ENGINE_PRODUCT_PLAN.md) and [M0/M1 roadmap](../ROADMAP.md). Avoid creating empty packages or placeholder APIs solely to imply progress.
