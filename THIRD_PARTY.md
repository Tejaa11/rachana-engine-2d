# Attribution and third-party policy

## Authorship

Rachana Engine 2D is created and maintained by Tejas Dadhich ([Tejaa11](https://github.com/Tejaa11)). Planning, documentation, and development use AI assistance and maintainer review.

The initial scaffold's documentation, banner, and repository-check code are distributed under the root [MIT license](LICENSE). Provider outputs and externally sourced media must have their own origin and usage records; the engine's code license does not replace those records.

## Inspiration

[LambdaEngine2D](https://github.com/devesh95official/LambdaEngine2D), by devesh95official, inspired the emphasis on modular engine architecture, examples, and accessible repository presentation. No code, branding, or media from that repository is included in this scaffold.

## Dependencies and services

The initial local check uses only Node.js built-in modules and has no npm package dependencies. CI uses GitHub-maintained Actions referenced in its workflow. New runtime libraries, fonts, speech tools, FFmpeg distributions, models, and providers will be documented when integrated, including their versions, relevant notices, and setup requirements.

## Media policy

The earlier Voxam/CareClinic work informed the engine design. Its supplied narration, logos, screenshots, private source material, rendered films, and archives are not included in this repository.

Every future public fixture or showcase must record origin and redistribution permission. Generated assets also need provider/model metadata and available usage information. Do not assume that all files in a private production workspace are suitable for public redistribution.
